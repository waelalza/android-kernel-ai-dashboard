ADB BINARIES REQUIRED
=====================

Place the following files in this folder:

1. adb.exe           - Android Debug Bridge executable
2. AdbWinApi.dll     - ADB Windows API library
3. AdbWinUsbApi.dll  - ADB Windows USB API library

Download from: https://developer.android.com/studio/releases/platform-tools

Steps:
1. Download "SDK Platform-Tools for Windows"
2. Extract the ZIP file
3. Copy the files listed above to this folder

The app will NOT work without these files!
